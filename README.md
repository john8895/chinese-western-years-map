# 中西曆年號歲次對照表

Quick-lookup converter between Western calendar years and traditional Chinese calendar systems.

## Live Demo

**https://john8895.github.io/chinese-western-years-map/**

## Features

- **Bi-directional lookup** — Western year ↔ Chinese calendar
- **Comprehensive data** — covers 干支 (Heavenly Stems & Earthly Branches), 生肖 (Chinese Zodiac), 民國 (ROC year), and historical era names (年號)
- **Visual aids** — stem/branch diagrams and traditional time-system charts
- **Zero dependencies** — pure HTML + CSS + JavaScript, works offline

## Use Cases

Commonly used in Taiwan for:
- Official documents (戶籍謄本) that use ROC year format
- Traditional ceremonies requiring 干支 year references
- Historical research and genealogy

## Tech Stack

Pure frontend — HTML + SCSS + vanilla JavaScript. Data stored in static JSON files.

## Getting Started

```bash
git clone https://github.com/john8895/chinese-western-years-map.git
# Open index.html in a browser — no build step needed
```
